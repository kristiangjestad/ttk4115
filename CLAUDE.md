# Arbeidsflyt

- Når en endring er ferdig og testet (`npx tsc --noEmit` og `npm run build` går gjennom), commit og push den rett til `main` på GitHub. Du trenger ikke spørre først.
- Repoet er offentlig. Ikke legg inn Canvas-eksport, PDF-er eller annet privat materiale.
- All tekst i appen er på norsk og skal være kort. Pek på eksamensoppgavene og fasitene i stedet for å skrive lange forklaringer.
