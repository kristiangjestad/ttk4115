Certain systems are well described by linear models on the following form:
                                             y = Du                                    (1)
Here, y is an output vector, u an input vector and D a constant matrix of suitable
dimension.

                                               y = Du
        Here, D is also a scalar.
        Suppose now that y is to be placed close to a reference r in such a way that the
        following quadratic cost function is minimized:
                                         J = Q(y − r)2 + Ru2
        Here, Q and R are positive numbers.
        Derive an analytical expression for K in the linear feedforward law u = Kr so that
        J is minimized.
        What happens to y given the feedforward law u = Kr when Q is made very large
        with respect to R? What happens when R is made very large with respect to Q?

        u = Kr so that J is minimized.
