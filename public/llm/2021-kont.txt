Problem 2
The name of the course you are taking is linear systems theory. Let a time invariant
system be defined by the equation ẋ(t) = F (x(t)), where x is a real vector with n elements.
a) State the two conditions on the function F for the system to be linear.
      The first condition is called additivity, and can be defined as follows:

                                 F (x1 + x2 ) = F (x1 ) + F (x2 )

      The second condition is called homogeneity, and can be defined as follows:

                                         F (αx) = αF (x)

      A function that satisfies both conditions also satisfies superposition:

b) If F and G are functions satisfying the linearity conditions, are the following two
      compositions linear?
        1. z = (F G)(x) = F (G(x))
        2. z = (F · G)(x) = F (x)G(x)
      We use the superposition property to test F G first:

                             F G(αx1 + βx2 ) = F (G(αx1 + βx2 ))

c) Give three reasons why linearity is a useful property in the context of dynamical
     systems.
     Some relevant points:
        • Linearity implies that the time-domain response of a system can be found as
          a superposition of inputs and initial values, thereby for instance allowing us
          to separate the zero-state response and the zero-input response.
        • Linearity makes it simple to determine stability properties globally.
        • Linearity allows global determination of observability and controllability.
        • Linearity allows eigenvalue analysis and the ability to design controllers using
          pole placement or LQR.
