Problem 9
In the laboratory assignments, when controlling the helicopter using measurements from
the IMU unit, you experimented with state estimation both in the form of a Luenberger
observer and a Kalman filter.
a) What are the main reasons that we use state estimation in control systems?
     There are several reasons that can be pointed out:
        • Unmeasurable states: In many real-world systems, not all internal states
          can be directly measured. State estimators use available noisy or incomplete
          measurements, combined with a mathematical model of the system, to infer
          the values of these unmeasurable states.
        • Noisy measurements: Sensor measurements are inherently noisy and can
          be corrupted by errors or interference. State estimation acts as a filter, pro-
          cessing these noisy measurements to provide a more accurate and reliable
          estimate of the system’s true state than any single measurement could offer.
        • Handling missing data: In some cases, sensor data might be temporarily
          unavailable due to communication failures, sensor malfunctions, or network
          issues. State estimation algorithms can often bridge these gaps by using the
          system model and previous estimates to predict the current state.
        • Redundant measurements: By incorporating redundant measurements,
          state estimation can improve overall robustness and reliability.
     For full score, at least two of these points should be covered in a good way.
b) What are the most important differences between using a Luenberger observer with
    pole placement, and using a Kalman filter? Comment on the tuning process, esti-
    mator performance, and other aspects you would like to include.
     There are several differences that can be pointed out:
        • The Luenberger uses a static estimator gain chosen based on pole placement,
          while the Kalman filter uses a dynamic estimator gain chosen based on min-
          imizing the sum of the estimation error variances.

                                          14

  • The Kalman gain is chosen based on the statistical properties of the sys-
    tem disturbances (specified using the Qd matrix) and the measurement noise
    (specified using the Rd matrix), both of which are assumed to be white noise
    processes.
  • Since Rd can often be set based on analysing the measurement noise, while
    the “true” value of Qd is hard to assess, Qd is typically used as a tuning
    parameter. By tuning elements along the diagonal of Qd we can affect the
    Kalman filter’s relative weighting of state estimates vs. measurements for
    individual model states.
  • The dynamic nature of the Kalman gain is not always important, since it will
    approach a stationary value. However, if measurements arrive at irregular
    intervals (measurements not being available at all time steps), the covariance
    matrix P[k] will change accordingly, indicating increasing uncertainty as time
    goes by without available measurements, and this will lead to the estimator
    dynamically changing the Kalman gain to put more emphasis on measure-
    ments after the estimator has gone for some time without measurements.
  • In the case where you measure all the model states, the Kalman filter com-
    putes posterior estimates that are a weighting between prior estimates and
    the measurements, and if you let the elements of Qd approach infinity (indi-
    cating a highly noisy process) the extreme case is that the posterior estimates
    become equal to the measurements. The measurement noise will not be am-
    plified, which can happen with a Luenberger observer of A − LC are placed
    too far into the left half plane. Note that this distinction is not quite as clear
    in the case where you measure only a subset of the states.
