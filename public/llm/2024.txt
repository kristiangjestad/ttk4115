Problem 4
Given a continuous time system:

                                ẋ = Ax + Bu,    y = Cx

Which of the following statements are true (note: more than one may be true):
a) The system can be diagonalized provided the A matrix is invertible.
b) The system can only be asymptotically stable if the A matrix is invertible.
c) The A matrix must be invertible for the system to have a time domain solution.
d) If the A matrix is non-invertible, the system is marginally stable.
e) If the A matrix is symmetric and negative definite, the system is asymptotically
      stable.
Taking the alternatives in turn:
a) False. Invertibility does not determine whether the matrix can be diagonalized.
b) True. If the matrix is not invertible it means at least one of its eigenvalues is 0. An
     eigenvalue in 0 means the systems is either marginally stable or unstable.
c) False. The system has a time domain solution regardless of the invertibility of A.
d) False. The system can have one or more eigenvalues in 0 and be unstable.
e) True. A symmetric matrix has only real eigenvalues, and if A is also negative definite,
     all eigenvalues are real and negative.
The correct ones are therefore b) and e).
